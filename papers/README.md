## Which document should I cite?

- Cite the **thesis** when referring to the complete study, extended methodology, literature review, or full experimental discussion.
- Cite the **conference paper** when referring to the concise peer-reviewed conference contribution. Until the archival record is available, state that publication is forthcoming.
- Cite the **software repository** through [`CITATION.cff`](../CITATION.cff) when reusing code or repository artifacts.
